# Changelog

## 3.1.0 — 2026-10-21

- Added a compact image editor for custom resize and crop dimensions.
- Added circular crops, common aspect ratios, and social-platform presets.
- Preserved the GNOME Shell radial overlay as the main Wayland interaction.
- Added Android App Bundle inspection, universal APK creation, APK signing,
  and direct AAB signing as separate actions.
- Added multi-file, archive, PDF, image, video, and audio smart actions.
- Added Nautilus integration and a compact GTK4/libadwaita settings window.
- Improved delayed GNOME Wayland drag-selection handling.
